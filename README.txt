AICTE Complaint Monitoring Dashboard — Front-end Prototype

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Internet is only needed for Google Fonts and Chart.js CDN; most layout and interactions are local.

WHAT IS INCLUDED
- Overview dashboard and sample charts
- Complaints list with search, status and priority filters
- Complaint registration with a keyword-based demo category suggestion
- Complaint details, activity timeline, assignment/reassignment
- Institutions directory with demo add flow
- Routing rules and human review queue
- Reports and CSV exports
- Notifications, users/roles table and audit log view
- Responsive layout for desktop and mobile

IMPORTANT LIMITATIONS
This is a static front-end prototype. It does NOT include a real Django backend, PostgreSQL database,
real authentication/authorization, persistent server-side storage, secure document uploads, email delivery,
or a trained AI model. Sample data, categories, destinations and metrics are fictional and for demonstration.
Do not use real complaint or personal data. Before production, verify the official AICTE organizational
directory and approved routing rules, and implement server-side validation, security, audit logging and access controls.
